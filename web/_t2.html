BBN TC2000

An MC88100 emulator running nX — BBN’s 4.3BSD for the Butterfly TC2000 — booted from a 1989 install tape, compiled to WebAssembly.

What you are looking at

Pressing Boot the machine downloads the kernel and the tape’s UFS filesystem (about 9 MB), then starts the emulator at the kernel’s entry point. What scrolls past is the real boot sequence: the MC88100 coming up, the 88200 CMMUs being programmed, the root filesystem getting mounted. When it reaches the point where the swapper goes idle, the emulator starts /bin/sh off the tape as a genuine nX process — real execve, real page faults, real scheduler — and hands it the terminal.

Things to try at the # prompt

  • ls /bin — what shipped on the tape
  • cat /etc/motd
  • df and ls -l /dev
  • echo $PATH, shell variables, pipelines
  • date — 1989, as configured
  • grep vt100 /etc/termcap
  • Ctrl+D — halt the machine

The terminal is a fixed 80×24 VT100, because that is what the emulator tells the guest it is; the whole thing is scaled to fit the box rather than reflowed. The banner offers exit as well as Ctrl+D, but this shell keeps going after exit — end-of-file is what actually stops the machine, in the browser and natively alike.

Putting it in your own page

Three tags and an element:

<link rel="stylesheet" href="vendor/xterm.css">
<link rel="stylesheet" href="tc2000.css">
<script src="vendor/xterm.js"></script>
<script src="tc2000.js"></script>

<tc2000-console style="height:560px"></tc2000-console>

Add autostart to boot without the click. For the imperative form, and for pointing the page at a different tape or a different nx88 command line, see web/README.md.
